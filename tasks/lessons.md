# Lessons Learned

- **Design Preference**: User selected "Deepak / AI Product Manager" as title/role.
- **Theme Preference**: Light mode default with dark mode toggle.
- **Interactive Elements**: Purely static/interactive cards with NO LLM chat bubbles or prompts.
- **Projects**: Project cards must support detailed modal/view with description, live demo link, and GitHub repository link.
- **Background**: Blue-dominant with purple/teal accents for mouse-tracking aurora background.
